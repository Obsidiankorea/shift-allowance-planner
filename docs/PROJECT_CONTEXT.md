# 프로젝트 맥락 및 대화 히스토리

작성일: 2026-10-07. 기준: 사용자 발언, 이번에 실제 분석한 Excel, 다시 읽은 과거 FAQ/PDF/HWPX. 과거 검토자료와 현행 공식 원문 확인 상태를 구분하며, 답변 근거가 확인되지 않는 내용은 질문/요구로만 기록한다.

## 목적

경상남도 재난안전상황실 교대근무자가 월별 예상 수당과 교육·출장·근무교환의 금전적 증감을 미리 보는 Windows 데스크톱 프로그램. 단순히 총액을 출력하는 것보다 **시간외수당이 0원이 되는 음수 구간**을 드러내는 것이 핵심이다.

사용자는 방재 6급이며 본인 본봉을 명시했다 (공개 저장소라 이름·금액은 문서에 남기지 않는다. 2026-10-08부터 본봉 초기값을 코드에서 빼고 직급·호봉 입력으로 받는다). 다른 차석/계장급은 본봉이 더 높을 수 있으므로 동일 금액으로 계산하면 안 된다.

## 논의의 흐름 (순서 요약)

1. 주·야·비·비 근무에서 어떤 달은 초과수당이 0이 되고 금액 차이가 커지는 이유를 질문.
2. 기준일수×8, 휴일근무시간 공제, 시간외 0 하한, 야간·휴일 별도 지급을 구분하려고 함.
3. 휴일 주간 9.5시간 중 8시간 공제와 나머지 1.5시간의 처리, 휴일 18~22시 처리, 월말 야간 귀속을 질문.
4. 연가·특가·공가 및 일반직/소방직 야간연가 시간 차이, 음수 상태에서 연가의 효과를 질문.
5. 비번활동 30분이 실제 산입·절사되는지, 초과 음수일 때 야간과 휴일의 상대적 금액을 질문.
6. 서로 평일 주간과 휴일 주간을 바꾸는 사례, 연가 사용을 위한 근무교환을 논의.
7. 연가보상비와 초과 8시간의 손익 분기, 직급·호봉별 본봉 임계점, 2026 봉급표 비교를 요청.
8. 경남 복무조례, 교대근무자의 연가 시간, 타 기관/소방의 운영근거를 질문.
9. 장기 휴가·출산·교육 결원 및 여름 휴가철을 이유로 사전 승인된 3교대 전환이 가능한지 질문.
10. 비번일 집합교육을 월 총근무시간에 더하는 소방 운영근거를 요청. 사용자는 소방에서 실제로 그렇게 운영한다고 설명.
11. 처음에는 개조식 FAQ/PDF/HWPX 등을 요청했으며, 이후 실행 가능한 수당 시뮬레이터로 요구가 구체화됨.
12. 이번 구현에서는 근무편성표를 입력받는 Python GUI, 사용자별 미래 월 편집·저장, AI 인계 문서를 요청.
13. (1.1, 2026-10-07) 야연/주연 등 연가 전환은 주간 9.5시간 근무가 8시간 산입으로 바뀌는 효과가 있지만, 단순 시간 비교로 끝내지 말고 연가보상비 기회비용과 비교하라고 요청. 사용자 예: 초과 −10시간인 달에 일반직 야연(15시간)을 쓰면 지급 초과는 5시간만 늘어 연가보상비 1일보다 적으므로, 연가를 쓰지 않고 비우는 편이 금전상 낫다. 2026 봉급표(소방 포함)와 산식 `기준 월봉급액 × 86% × 1/30`을 가져오고 개인별 호봉을 입력하게 해 달라고 요청. 이어서 본봉+수당 합계 카드는 필요 없다고 하여 삭제.
14. (1.2, 2026-10-07) 연가 vs 연가 안 씀 비교는 개인 달력에 야연/주연 등 연가를 넣었을 때만 보여 달라고 요청. 특가·공가는 어차피 쓰는 휴가라 비교 불필요, 연가만 보상비라는 선택지가 있어 기회비용 비교 대상. 오른쪽 설명이 난잡하니 `총근무 nnn시간` 과 `공제 nnn시간 = (nn일 × 8시간) + 휴일(n일 × 8시간)`(휴일은 윗첨자)을 맞대어 보여주고 나머지는 간략히, 맨 위 `?` 아이콘에 법적 근거(왜 시간을 공제하는지)·하이퍼링크·설명을 정리해 달라고 요청.
15. (1.3, 2026-10-07) 달력의 `10월` 옆에 그 달 정규근무 일수(20일, 21일 등) 표시 요청. 또 오른쪽 아래에 **아무것도 손대지 않았을 때(주야비비) 대비 변경 전후 손익**을 넣어 달라고 요청. 사례: 누군가의 부탁으로 근무를 바꿔 연가를 썼을 때, 원래 초과가 마이너스라 주말을 더 서서 이득일 수도 있고, 연가가 마이너스에 상계되어 연가보상비로 받을 돈보다 손해일 수도 있다.
16. (1.4, 2026-10-07) 엑셀로 가져온 달은 이미 연가를 쓰고 근무자를 바꾼 편성이라 1.3 카드가 "변경 없음"으로 나오는 문제 지적. (1) 주야비비를 전혀 손대지 않았을 때 대비 변경사항과 (2) 지금 저장된 편성 대비 추가로 바꿨을 때 금액 차이를 **구분해** 비교해 달라고 요청. 앱은 (2)의 "저장된 편성"을 가져온 엑셀 편성표(없는 달은 주야비비)로 해석했다.
17. (1.5, 2026-10-07) (2)는 엑셀 편성이 아니라 **사용자가 만든 저장파일** 기준이라고 정정. 예: 현재 상태를 `10-7홍길동 수정`으로 저장했으면 그 파일 대비 변경. 카드 오른쪽 위에 파일 열기 아이콘을 두어 비교할 저장파일을 바꿀 수 있게 요청. 또 시작 시 사용자 선택 + "다음번에 다시 선택하지 않기", 선택 후 직급·호봉 입력으로 월급 자동 반영, 해가 바뀌면 "연간 봉급표가 갱신되지 않았습니다. 확인해주세요" 경고와 바이브코딩 또는 세부설정으로 갱신할 수단, 저장 없이 종료 시 "저장하시겠습니까?" 확인을 요청. 이어서 손익 결과 뒤에 아이콘을 두고, 연가보상비를 받았을 때 대비까지 포함해 **누구라도 이해할 수 있는 세부 계산 근거 팝업**을 요청.
18. (1.6, 2026-10-07) EXE 빌드 도중 중단 후, 사용자가 작성한 **"만든 이유"**(마이너스 초과에서 교육·출장·주연/야연이 마이너스를 먼저 메우는 문제, 훈령 제5조에 따라 연가 없이 근무조정을 먼저 검토하려는 목적)를 시작 팝업으로 띄우고 `다시 표시하지 않기`를 두도록 요청. 또 "현업근무자 등의 세부 연가방침은 각 기관방침에 따른다"는 이해를 바탕으로 **지방공무원 복무 관련 법령 → 경상남도 → 상황실 훈령** 계통으로 근거 신뢰도를 높이고 각 법령에 하이퍼링크를 걸어 달라고 요청. 사용자가 훈령 제5조 원문 화면을 제공.
19. (1.6.1, 2026-10-07) 사용자가 앱에서 일반직 야연 15시간·소방 8시간 산정이 맞는지 확인 (코드상 직급명이 '소방'으로 시작하면 8시간, 아니면 15시간; 야공·야병은 직렬 구분 없이 15시간). 다른 PC에서 EXE가 `module 'numpy' has no attribute 'short'`로 실행되지 않음을 보고. 시작 안내에서 조례의 시간외 → 연가 전환은 해당사항이 별로 없으니 빼고, 소방 근거를 안내에 넣으라고 요청.
20. (1.6.2, 2026-10-07) 사용자가 "만든 이유" 문안을 수정해 제공하고 개선 제안을 요청. ELIS 경남 자치법규 목록에 상황실 훈령이 있으니 갱신·링크를 요청. 훈령 제5조를 논리적으로 자세히 정리하되 ④ 각 호(재난, 연휴·명절·연말연시, 연가 또는 법에 따른 휴가·교육훈련, 기타 효율적 운영 = 자체 내부결재)를 구분하고, "실무적으로는 연가를 안 쓰고 연가보상비를 받는 것이 실질적인 문제"라고 적어 달라고 요청.
21. (1.6.3, 2026-10-07) 제5조 정리의 2호 뒤에 "여름휴가" 링크를 두고, 사용자가 제공한 검토 내용(훈령 2024.7.25 전부개정본, 제4항 2·3·4호의 여름 휴가철 적용, 제2호 "같은"의 해석과 유권해석 부재, 연가 처리 구분, 결론)을 보고서 형태 팝업으로 정리하고, 공문은 "지방공무원 복무규정 및 재난안전상황실 운영 규정에 따라" 올리면 된다는 의견을 넣어 달라고 요청. 앱은 원문의 개인 호칭을 일반 표현으로 바꿔 수록.
22. (1.7, 2026-10-08) 메뉴 간략화 요청: 큰 제목 삭제, 엑셀 가져오기·설정·저장 등 버튼을 오른쪽 위 ? 왼쪽의 메뉴 아이콘 드롭다운으로 통합, 예상 수당 합계·차감 후 초과시간은 작게 한 줄, "원래 근무표 대비 수당"은 삭제. 또 수정할 때마다 +실익/−손해가 오른쪽 위 오버레이로 잠깐 뜨고, 그 오버레이나 변경 히스토리를 누르면 산식 근거가 나오도록 요청.
23. (1.8, 2026-10-08) 야간을 비번으로 바꾸면 −63,890원 정도로 수당은 줄지만, 초과가 마이너스가 되어 근무를 줄인 것에 비해 손해가 크지 않다는 점도 표시해 달라고 요청.
24. (1.8) 「재난상황보고서」처럼 업데이트 기능: GitHub 버전관리 + 업데이트 확인, 확인 후 자동 업데이트는 설정에서. (그 프로그램은 비공개 저장소 + `git pull --ff-only`이며 EXE에서는 꺼짐. 이 프로그램은 다른 PC에서 EXE로 쓰므로 GitHub Releases 방식을 더함.)
25. (1.8) "만든 이유" 등 안내문을 마크다운으로 바로 고칠 수 있게, 마크다운 원문도 확인 가능하게, 옵시디언 같은 문서로. 편집 아이콘 → 연결 프로그램 설정.

## 혼동을 피해야 할 표현

- `총근무일수 - 복무일수 - 휴일근무일수`라는 대화 중 표현을 그대로 계산식에 쓰지 않는다. 시간 단위로 통일한다.
- `160시간`은 매월 고정값이 아니다. 제공된 2026년 9월은 기준일 20일이라 160시간이다.
- 음수 초과시간은 그 자체로 급여에서 해당 금액을 공제하는 부채가 아니다. 현재 모델에서는 시간외수당 산정용 음수 잔여값이다.
- 앱의 `연가 순실익`은 **수당 증가 − 사용한 연가일수의 보상비**라는 금전 비교다. 연가 사용 권리·승인, 보상 대상 여부, 휴식의 가치는 판단하지 않는다. 보상 한도 밖이거나 어차피 소멸하는 연가는 기회비용이 0이므로 사용자별 `연가보상 대상 N`으로 둔다.
- `연가 = 초과수당 현금 전환`은 사용자가 논의한 실무 효과이며 법적 일반 명제가 아니다. 쉬는 대신 실제 근무하는 경우와 결근 대신 연가 처리하는 경우의 비교 기준을 명시해야 한다.
- 연가를 쓴 날 무조건 누군가 대신 서야 한다는 현장의 제약은 사용자의 설명이다. 모든 기관에 공통인 법적 전제로 확대하지 않는다.
- 추가 교육시간의 실익이 0이라는 것은 **그 시뮬레이션의 시간외수당 증가가 없다**는 뜻이다. 교육 자체의 필요성이나 승인 여부를 평가하지 않는다.

## 실제 입력 자료

### 근무 편성표 (주 입력)

- 파일: `2026년 10월 재난안전상황실 관리팀 근무 편성표 v3.xlsx`
- 시트1 `근무편성표`: 날짜, 주간/야간, 조, 반장·반원 이름, 비고.
- 시트2 `법정공휴일 및 근무자 입력 시트`: 명부, 조, 공휴일 참고목록, 4교대 순서.
- 시트2 명부가 기준 소속이다. 대체근무자의 해당 행 조를 소속 변경으로 해석하지 않는다.
- 비고 연가/교육과 실제 근무자 이름이 함께 중요하다.

### 수당 산출표 (회귀 검증 및 기존 단가 근거)

- 파일: `9월 재난상황관리팀 초과근무수당 산출내역서(공람완료)(최종)_(1).xlsx`
- 2026년 9월, 12명.
- `월중 근무내역`, `초과근무수당산출내역서`, `비번활동 내역`, `기준표` 등.
- 명부 실명/원본 Excel은 배포에 넣지 않고 사용자가 선택한다.
