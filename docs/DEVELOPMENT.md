## 설계 결정

1. 법적 자동판정과 계산을 분리했다. 앱은 입력된 인정시간의 효과를 계산한다.
2. 급여 전체 대신 수당만 표시한다. 본봉은 연가보상비 계산에만 쓰고 본봉+수당 합계 카드는 1.1에서 사용자 요청으로 삭제했다.
3. 기본값은 원본 Excel 회귀 호환. 개선모드는 시간절사를 끄는 형태로 제공한다.
4. 입력 월의 실제 편성은 보존하고 미래 월만 조별 주기에서 생성한다.
5. 날짜 수정은 overrides로 저장해 원래 편성과 비교 가능하게 했다.
6. JSON 저장은 임시파일 작성 후 os.replace로 교체한다. 손상된 자동저장파일은 시작 시 별도 백업한다.
7. 교육 대체시간과 추가시간을 다른 필드로 분리했다.
8. 공휴일은 패키지 생성+수동 예외. Excel의 노동절 등 목록을 검증 없이 모두 덮어쓰지 않는다.
9. 직원 이름의 공백을 제거하지만 동명이인은 자동 병합하지 않는다. 추가 월 가져오기에서는 이름+직급으로 연결한다.
10. 미래 달의 단가는 자동 인상하지 않고 설정된 기준연도를 표시한다.

EXE 다른 PC 오류 (1.6.1, 2026-10-07): 사용자가 `_internal\`이 최상위에 있는 zip을 만들어 다른 PC에 풀었더니 `module 'numpy' has no attribute 'short'`로 시작 실패. 이 PC에서 `_internal\numpy` 빈 폴더를 넣어 같은 트레이스백을 재현했다 (openpyxl `compat/numbers.py`의 선택적 `import numpy`가 namespace 폴더를 잡음). PYTHONPATH·실행 위치로는 재현되지 않음. 추정 원인: 다른 프로그램의 `_internal`과 같은 위치에 풀려 폴더가 섞임. 조치: EXE에서는 `importer.py`가 `sys.modules['numpy']=None`으로 선택적 import를 막고, 빌드에서 numpy 제외, `build_exe.py`가 빈 numpy 폴더를 넣은 상태로도 자체 점검, zip은 `교대근무수당플래너\` 폴더째 묶는다. 또 빌드 중 `배포` 폴더의 EXE가 실행 중이면 PyInstaller가 폴더를 지우다 실패해 반쯤 지워졌으므로, 이제 `build\dist`에서 빌드·점검 후 `배포` 폴더를 이름 바꾸기로 교체하고, 잠겨 있으면 교체를 미룬다.

## 릴리스·업데이트 절차 (1.8)

1. `version.py`의 `VERSION`을 올리고 `CHANGELOG.md`에 `## <VERSION> — 날짜` 항목을 쓴다.
2. 테스트(`python -m unittest discover -s tests`) 통과 후 `build_exe.py --release` → EXE 빌드·자체 점검·`배포/교대근무수당플래너_v<VERSION>.zip` → `gh release create v<VERSION>` (노트 = CHANGELOG 해당 절).
3. 사용자 PC의 EXE는 시작할 때(설정에 따라) `https://api.github.com/repos/<REPO>/releases/latest`를 확인한다. **비공개 저장소면 토큰 없이 확인할 수 없다** (404 → "확인 실패"로 표시, 최신으로 보지 않음).
4. 교체 순서: 옛 EXE가 zip을 `%TEMP%/sap_update_*`에 풀고 새 EXE를 `--finish-update <프로그램 폴더> <옛 PID>`로 띄운 뒤 종료 → 새 EXE가 옛 PID 종료를 기다려 폴더를 `_이전버전`으로 이름 바꾸고(잠겨 있으면 복사) 새 파일을 복사 → `--updated`로 다시 실행.
5. 릴리스 첨부 파일은 영문 이름 `shift-allowance-planner_v<VERSION>.zip`으로 올린다 (GitHub가 한글을 지워 `_v1.8.0.zip`이 됐던 문제). 업데이트는 이름과 무관하게 첫 `.zip` 첨부를 받는다.
6. 공개 저장소이므로 커밋 작성자는 저장소 로컬 설정 `Obsidiankorea <…@users.noreply.github.com>`을 쓴다 (전역 git 설정의 실명·기관 이메일 노출 방지). 코드·문서·예시 화면에 실제 직원 이름·본봉을 넣지 않는다. 실제 엑셀 대조 테스트의 확인용 이름은 환경변수 `TEST_MAIN_PERSON`으로만 준다.
7. git 저장소에는 `.gitignore`로 실제 근무 데이터(`*.xlsx`, 루트 `*.json` 저장 시나리오)와 `배포/`, `build/`를 올리지 않는다.
