# 문서 폴더 사용법

이 폴더의 `.md` 파일은 프로그램 안의 안내문(시작 안내, ? 도움말, 여름휴가 검토 등)입니다. 파일을 고치고 저장하면 열려 있는 안내 창에 바로 반영됩니다.

| 파일 | 어디에 나오나 |
|---|---|
| 시작 안내 | 프로그램을 켤 때 뜨는 창 |
| 도움말 | 오른쪽 위 ? 버튼 |
| 만든 이유 · 훈령 제5조 정리 · 근거 계통 요약 · 산식과 근거 | 위 두 문서에 끼워 넣는 조각 |
| 여름휴가 검토 | 훈령 제5조 정리의 "여름휴가 ▸" 링크 |

## 쓸 수 있는 문법 (옵시디언과 같음)

- `![[문서 이름]]` — 다른 문서를 그 자리에 끼워 넣기
- `[[문서 이름]]`, `[[문서 이름|보일 글자]]` — 누르면 그 문서가 새 창으로 열리는 링크 (표 안에서는 `|` 대신 `\|`)
- 표, **굵게**, 목록, `> 인용`(회색 상자), ```` ``` ```` 코드 블록(공문 예시처럼 줄 맞춤 유지), `<sup>위첨자</sup>`
- `[공식 확인]`, `[기존 검토 기록]`, `[엑셀 재현]`, `[사용자 제공 원문]`, `[미확정]` 은 프로그램에서 색이 입혀집니다.
- `<span class="muted">…</span>` 은 회색 작은 글씨입니다.

## 편집 프로그램

안내 창의 ✎ 편집은 설정 → `문서·업데이트` 탭에서 고른 프로그램으로 엽니다 (Windows 기본 연결 프로그램 / Obsidian / 직접 지정). Obsidian을 쓰려면 이 `문서` 폴더를 Obsidian에서 "폴더를 보관소로 열기"로 한 번 등록하세요.

⚠️ EXE 폴더의 문서를 고친 경우, 프로그램을 업데이트하면 새 버전의 문서로 바뀌고 고친 문서는 `…_이전버전` 폴더에 남습니다. 계속 쓰려면 원본 저장소의 `문서` 폴더에도 반영하세요.
