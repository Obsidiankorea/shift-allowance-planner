# 교대근무 수당 플래너

Windows 11 스타일의 Python 대화상자 프로그램입니다. 실제 지급명세서가 아닌 근무편성·교육계획 비교용입니다.

## 실행 (EXE)

`배포\교대근무수당플래너\` 폴더를 통째로 원하는 곳에 복사한 뒤 `교대근무수당플래너.exe`를 더블클릭합니다. Python 설치가 필요 없습니다.

- 다른 PC로 옮길 때는 `배포\교대근무수당플래너_v버전.zip`을 쓰세요. zip 안에 `교대근무수당플래너` 폴더째 들어 있으니 **새 빈 폴더에** 풀고 그 안의 EXE를 실행합니다. 다른 프로그램 폴더 위에 겹쳐 풀면 파일이 섞여 실행되지 않을 수 있습니다.
- 폴더 안의 `_internal` 폴더가 함께 있어야 실행됩니다. EXE 파일만 따로 옮기지 마세요 (바로가기를 만들어 바탕화면에 두세요).
- 처음 실행할 때 Windows SmartScreen이 "알 수 없는 게시자" 경고를 띄울 수 있습니다. 직접 빌드한 파일이라 서명이 없기 때문입니다.
- 저장 데이터는 EXE 폴더가 아니라 `%LOCALAPPDATA%\ShiftAllowancePlanner\`에 남으므로, EXE를 새 버전으로 바꿔도 작업이 유지됩니다.
- 코드를 고친 뒤 EXE를 다시 만들려면 `build_exe.cmd`를 더블클릭합니다 (아래 Python 실행 환경이 먼저 필요). 빌드는 `build\dist`에서 먼저 점검한 뒤 `배포` 폴더를 교체합니다. 그 폴더의 프로그램이 실행 중이면 교체를 미루고 zip만 만듭니다. 프로그램을 닫고 다시 실행하세요.

## 화면 구성

- **맨 위 한 줄**: 사용자 선택 · `예상 수당 ○원 · 차감 후 초과 ±○시간` · 오른쪽 끝에 **☰ 메뉴**와 **? 도움말**.
- **☰ 메뉴**: 엑셀 가져오기 / 저장(Ctrl+S) · 다른 이름으로 저장 · 불러오기 / 변경 히스토리 · 연간 CSV 내보내기 · 가져오기 확인사항 / 사용자·호봉 · 설정.
- **수정 손익 알림**: 날짜 편집·수정 취소·월 조정값·설정·직급/호봉을 바꿀 때마다 오른쪽 위에 `+○원 실익` / `−○원 손해`가 몇 초간 뜹니다. 그 수정 **바로 직전과 비교**한 그 달 손익(수당 차이 − 늘어난 연가일수 × 연가보상비)입니다. 알림을 누르면 계산 근거 창이 열립니다.
- **변경 히스토리** (메뉴): 이번 실행에서 한 수정과 각각의 수당 차이·연가보상비·손익 목록입니다. 줄을 더블클릭하거나 `계산 근거 보기`를 누르면 계산 근거가 나옵니다. 프로그램을 끄면 비워집니다.

## 안내 문서 고치기 (마크다운)

시작 안내, ? 도움말, 여름휴가 검토 같은 안내문은 프로그램 폴더의 `문서\*.md` 파일입니다 (옵시디언과 같은 마크다운).

- 안내 창 오른쪽 위 **원문 (마크다운)**: 원문을 보고 그 자리에서 고쳐 `원문 저장`. 여러 문서를 이어 붙인 창은 위 목록에서 고칠 문서를 고릅니다.
- **✎ 편집**: 고를 문서를 **연결 프로그램**으로 엽니다. 연결 프로그램은 ☰ → 설정 → `문서·업데이트` 탭에서 고릅니다 (Windows 기본 연결 프로그램 / Obsidian / 직접 지정). Obsidian은 `문서` 폴더를 "폴더를 보관소로 열기"로 한 번 등록하세요.
- 다른 프로그램에서 저장하면 열려 있는 안내 창이 1초 안에 다시 그려집니다.
- 문법: `![[문서]]` 다른 문서 끼워넣기, `[[문서|글자]]` 새 창 링크(표 안에서는 `\|`), 표·굵게·목록·`> 인용`(회색 상자)·코드 블록. `[공식 확인]` `[미확정]` 같은 상태 표시는 자동으로 색이 입혀집니다. 자세한 것은 `문서\_이 폴더 사용법.md`.
- EXE 폴더에서 고친 문서는 다음 빌드 때 원본 `문서` 폴더로 자동 역반영됩니다. 업데이트로 프로그램이 바뀌면 고친 문서는 `…_이전버전` 폴더에 남습니다.

## 업데이트

저장소: https://github.com/Obsidiankorea/shift-allowance-planner (공개) · 릴리스: https://github.com/Obsidiankorea/shift-allowance-planner/releases

- **EXE**: ☰ → `업데이트 확인` 또는 시작할 때 자동 확인. GitHub 릴리스에 새 버전이 있으면 받아서 프로그램 폴더를 바꾸고 다시 켭니다. 옛 폴더는 `교대근무수당플래너_이전버전`으로 남습니다. 저장 데이터(`%LOCALAPPDATA%`)는 그대로입니다.
- **소스 실행(git 저장소)**: 「재난상황보고서」와 같은 방식으로 `git pull --ff-only`. 이 PC에서 고친 파일과 겹치면 받지 않고 이유를 보여 줍니다. 받은 뒤 다시 켜야 반영됩니다.
- **설정 → 문서·업데이트**: `시작할 때 업데이트 확인`(기본 켬), `새 버전이 있으면 자동으로 받아 설치`(기본 끔, 켜면 받아 둔 뒤 지금 다시 시작하거나 끌 때 적용).
- 확인에 실패하면(인터넷 차단 등) "최신"으로 표시하지 않고 실패라고 알립니다.
- 개발자: `version.py`의 `VERSION`을 올리고 `CHANGELOG.md`에 같은 버전 항목을 쓴 뒤 `.venv\Scripts\python.exe build_exe.py --release`를 실행하면 `v버전` GitHub 릴리스에 `shift-allowance-planner_v버전.zip`이 올라갑니다 (GitHub가 첨부 파일 이름의 한글을 지우므로 영문 이름으로 올림).

## 실행 (Python 소스)

1. Windows에 Python 3.11 이상 64비트를 설치합니다. 설치 시 `Add python.exe to PATH`를 선택합니다.
2. 압축을 풀고 `start_windows.cmd`를 더블클릭합니다.
3. 최초 실행은 인터넷 연결이 필요합니다. 전용 가상환경에 필요한 패키지를 설치합니다.
4. 오른쪽 위 메뉴(☰) → `엑셀 가져오기`에서 **2026년 10월 재난안전상황실 관리팀 근무 편성표 v3.xlsx**를 선택합니다.
5. 처음 시작하면 **만든 이유와 근거 계통** 팝업이 뜹니다. `다시 표시하지 않기`를 체크하면 다음부터 뜨지 않으며, 같은 내용은 오른쪽 위 ? 도움말에서 언제든 볼 수 있습니다.
6. 이어서 **사용자 선택** 창에서 본인을 고르고 직급·호봉을 넣습니다. 월 봉급이 봉급표에 따라 바로 바뀝니다. `다음번에 다시 선택하지 않기`를 체크하면 다음부터 이 창 없이 그 사용자로 시작합니다. 나중에 메뉴(☰) → `사용자·호봉`으로 다시 열 수 있습니다 (여기서 체크를 풀면 시작 창이 다시 나옵니다).
7. 연도가 바뀌었는데 봉급표가 아직 지난해 것이면 시작할 때 **"연간 봉급표가 갱신되지 않았습니다. 확인해주세요"** 경고가 뜹니다. 아래 `봉급표 갱신`을 참고하세요.

터미널로 실행하려면:

```console
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

EXE는 PyInstaller로 만듭니다 (`build_exe.cmd` → `build_exe.py`). 빌드 직후 EXE를 점검 모드로 실행해 한국 공휴일(추석)·10월 계산·도움말·창 그리기가 되는지 확인합니다. 이 점검은 임시 폴더를 쓰므로 실제 작업 데이터를 건드리지 않습니다.

## 월별 계획과 저장

- 엑셀에 있는 달: 실제 편성표를 사용합니다. 반장·반원 이름의 공백을 제거하고 시트2 명부에 연결합니다.
- 엑셀에 없는 달: 가져온 조별 순서를 **주 → 야 → 비 → 비**로 계속 이어 생성합니다. 연도 변경과 윤년도 처리합니다.
- 자동 생성은 최근 편성표에서 추정한 기준일과 순서를 사용합니다. `설정 → 4교대 주기`에서 확인·수정하세요.
- 날짜를 더블클릭하거나 `선택 날짜 편집`에서 연가·특가·공가·교육·출장 등을 설정합니다.
- 사용자별 수정은 서로 독립적입니다. 선택한 날짜의 수정 취소는 엑셀/자동 생성 기준으로 복귀합니다.
- 작업 중 변경은 `%LOCALAPPDATA%\ShiftAllowancePlanner\autosave.json`에 바로 기록되어 프로그램이 갑자기 꺼져도 남습니다.
- `다른 이름으로 저장`: 모든 사용자와 월별 수정안을 JSON 파일로 저장합니다. 기본 이름은 `10-07 홍길동 수정.json`처럼 날짜·사용자입니다. 이름을 달리해 여러 시나리오를 보관할 수 있습니다.
- 저장·불러오기·다른 이름으로 저장은 오른쪽 위 메뉴(☰)에 있습니다.
- `저장` (Ctrl+S): 지금 작업 파일에 덮어씁니다. 파일이 없으면 `다른 이름으로 저장`과 같습니다. 창 제목에 작업 파일 이름이 나오고, 저장 뒤 바뀐 것이 있으면 `*`가 붙습니다.
- 저장하지 않고 끄거나 다른 파일을 불러오면 **"저장하지 않은 변경이 있습니다. 저장하시겠습니까?"**가 나옵니다. `저장 안 함`을 고르면 다음 시작은 마지막으로 저장한 상태에서 시작합니다.
- `불러오기`: 저장된 사용자별 수정안을 열고, 그 파일이 작업 파일이 됩니다.
- 추가 월의 엑셀을 가져오면 이름·직급이 같은 사용자의 기존 월과 수정안을 유지합니다. 같은 월의 엑셀을 다시 가져와도 수동 수정안이 우선합니다. 새 엑셀을 그대로 적용하려면 해당 날짜의 수정 취소를 사용하세요.
- 새 편성표 명부에 없는 사용자는 새 프로젝트의 사용자 목록에서 제외됩니다. 인사변경 전에는 다른 이름으로 저장해 보관하세요.
- 명부·조 이름·직급·호봉·본봉·단가·주야간 산입시간·연가보상비 설정은 설정 대화상자에서 변경 가능합니다. 사용자/조/단가 행 추가·삭제도 가능합니다.

## 교육시간 입력: 두 가지 구분

| 목적 | 입력 |
|---|---|
| 해당일 근무를 교육으로 대체 | 기본 근무 `교육`, `교육·출장으로 대체한 시간` 입력 |
| 원래 근무를 유지하면서 추가 교육 | 기존 코드 유지, `기존 근무에 추가할 교육시간` 입력 |
| 비번에 교육 | 기본 근무 `비`, 추가 교육시간 입력 |
| 출장 | 위와 같은 방식으로 출장 칸 사용 |
| 추가 근무 | 기타 추가 근무시간 입력 |

추가 입력칸은 모두 합산됩니다. 동일 교육을 기본 근무와 추가 입력에 중복 입력하지 마세요. `추가 교육/근무 가정`은 비교만 하며 달력에는 저장되지 않습니다. 실제 시나리오로 남기려면 날짜 편집을 사용하세요.

교육·출장의 초과근무 산입 가능 여부는 이 프로그램이 판정하지 않습니다. 해당 기관에서 인정된 시간을 입력하는 시뮬레이션입니다. 수당 차이만으로 의무교육 이수 여부를 결정하는 도구는 아닙니다.

## 오른쪽 패널 보는 법

맨 위에 그 달의 **총근무시간과 공제시간**을 나란히 보여줍니다.

```text
총근무  182시간
공제    184시간 = (20일 × 8시간) + 휴일(3일 × 8시간)   ← '휴일'은 윗첨자
초과     -2시간   시간외수당 0원
```

달력 위 `10월 2026` 옆에는 그 달의 **정규근무 일수·시간**(예: 정규근무 20일 · 160시간)이 나옵니다. 공제 = 평일 기준일 × 8시간 + 휴일근무일 × 8시간입니다. 총근무가 공제보다 많아야 시간외수당이 붙습니다. 그 아래에는 선택한 날짜와, 연가를 쓴 날이면 연가 비교가 나옵니다. 왜 이 시간들을 빼는지와 법적 근거 링크는 오른쪽 위 **?** 버튼에 정리했습니다.

## 변경 전후 손익 (두 가지 기준)

오른쪽 패널 맨 아래에 카드 두 개가 나옵니다. 둘 다 `수당 차이 − 더 쓴 연가일수 × 연가보상비`로 최종 이득/손해를 보여줍니다.

| 카드 | 무엇과 비교하나 | 언제 보나 |
|---|---|---|
| **주야비비 원형 대비** | 연가·근무교환을 전혀 하지 않은 순수 주→야→비→비 | 엑셀 편성표에 이미 들어간 연가·교환까지 포함해 이 달이 결과적으로 이득인지 |
| **「저장파일 이름」 대비 변경** | 저장해 둔 시나리오 파일 (예: `10-7홍길동 수정`) | 그 파일을 저장한 뒤 내가 날짜를 더 바꾸면 얼마가 달라지는지 |

- 두 번째 카드의 기준은 기본으로 **지금 작업 파일**(마지막으로 저장하거나 불러온 파일)입니다. 카드 오른쪽 위 **폴더 아이콘**을 누르면 다른 저장파일을 기준으로 고를 수 있고, 고른 파일은 다음 실행에도 기억합니다.
- 저장 직후에는 "저장한 뒤 이 달에 바꾼 것이 없습니다"가 나옵니다. 날짜를 더 바꾸면 그 변화만 계산됩니다.
- 저장파일이 하나도 없으면 "다른 이름으로 저장"으로 기준 파일을 만들라는 안내가 나옵니다. 그 파일에 현재 사용자가 없으면 그렇게 표시합니다 (사용자는 id → 이름+직급 → 이름 순으로 찾습니다).
- 날짜는 같은데 설정(단가·호봉·조정값)이 달라 금액이 다르면 "날짜 변경 없음 (설정·조정값 차이)"로 표시합니다.

각 카드에는 바뀐 날짜 목록(예: `16일 야→비 · 17일 비→주`), 초과시간 변화, 시간외·야간·휴일 수당 차이, 연가보상비, 최종 손익이 나옵니다.

최종 손익 뒤의 **ⓘ 계산 근거**를 누르면 누구나 따라 계산할 수 있게 풀어 쓴 창이 열립니다. 연가일 카드(연가 쓸 때 vs 안 쓰고 비울 때)에도 같은 링크가 있습니다.

1. 한 줄 요약: 예) "수당은 87,250원 늘지만, 연가를 1일 더 써서 나중에 받을 수 있던 연가보상비 102,627원을 못 받게 됩니다. 합치면 −15,377원, 손해입니다."
2. 무엇을 비교했나 (기준과 지금)
3. 바뀐 날짜별 근무 인정시간·야간시간·휴일근무 변화
4. ① 근무시간 → 초과시간: 총근무 − 정규근무(평일×8) − 휴일근무 공제(×8) = 초과, 마이너스면 시간외 0시간인 이유
5. ② 수당: 시간 × 단가 = 금액 (시간외·야간·휴일, 10원 미만 버림)
6. ③ 연가보상비: 월 봉급 × 86% ÷ 30 = 1일 보상비, 연가 사용일수 기준→지금, 보상비 영향
7. ④ 최종 손익 = 수당 차이 + 연가보상비 영향 연간표에도 `주야비비 대비 손익`, `저장파일 대비 손익` 열이 있습니다.

예: 부탁을 받아 금요일 야간을 야연으로 빼고 토요일 주간을 대신 서면, 휴일수당·시간외는 늘고 야간수당은 줄어 수당은 +87,250원이지만 연가 1일(약 102,627원)을 써서 최종 −15,377원 손해입니다 (일반6 11호봉, 10월 편성표 기준). 원래 초과가 크게 마이너스인 달이면 같은 교환이 이득일 수도 있습니다.

## 봉급표 갱신

봉급표는 매년 바뀝니다. 프로그램에는 2026년 인사혁신처 봉급표(일반직 별표3, 소방 별표10)가 들어 있습니다. 올해 연도가 봉급표 연도보다 크면 시작할 때 경고가 뜹니다. 바꾸는 방법은 둘 중 하나입니다.

1. **설정 → 봉급표 탭**: 인사혁신처 봉급표 페이지에서 표를 복사합니다. 1호봉 첫 칸을 선택하고 `클립보드 표 붙여넣기`를 누른 뒤, 연도를 올해로 바꾸고 확인합니다. 열 순서(일반1~9, 소방정감~소방사)는 화면의 직급 순서와 같아야 합니다. `내장 2026년 표로 되돌리기`로 원래 표로 돌아갈 수 있습니다. 이렇게 바꾼 표는 저장파일 안에 함께 저장됩니다.
2. **AI(바이브코딩)**: "`pay_tables.py`를 20XX년 공무원 봉급표로 갱신해 줘"라고 요청합니다. 절차는 `docs/DEVELOPMENT.md`에 있습니다.

연도를 올해로 바꿔야 경고가 사라집니다. 수당 단가(시간외·야간·휴일)도 해마다 바뀌므로 `설정 → 수당 단가`도 함께 확인하세요.

## 연가 vs 연가보상비

주간 근무(9.5시간)를 주연으로 바꾸면 8시간이 산입되어 "일하지 않고 8시간 초과"를 얻는 것처럼 보입니다. 하지만 그 연가를 쓰지 않으면 연가보상비를 받습니다. 그래서 **달력에 연가(주연·야연·당연)를 넣은 날**을 선택하면 두 금액을 비교해 보여줍니다.

- **연가로 받는 수당**: 그 날을 연가로 둘 때와 연가 없이 비워 둘 때의 월 수당 차이.
- **포기하는 연가보상비**: 연가보상비 1일 = 본봉 × 86% ÷ 30.
- **결과**: 둘의 차이와 `연가 쓰는 게 유리 / 안 쓰는 게 유리`. 손익분기(연가로 생긴 시간 중 몇 시간이 시간외로 지급돼야 이득인지)도 함께 표시.
- **특별휴가·공가·병가**는 연가일수를 줄이지 않아 보상비와 비교하지 않습니다.
- **연간표**: `월별 교육·근무·연가 실익` 탭의 `연가 손익` 열에 연가를 넣은 달만 그 달 연가 전체의 손익이 나옵니다.
- **호봉 입력**: 시작 창이나 메뉴(☰) → `사용자·호봉`, 또는 `설정 → 사용자`에서 `호봉`을 입력하면 2026 공무원 봉급표(일반직 별표3, 소방 별표10)에서 본봉을 찾습니다. 호봉을 비우면 `본봉 직접입력` 값을 씁니다. 연봉제 등 봉급표가 맞지 않으면 호봉을 비우고 직접 입력하세요.
- **연가보상 대상 Y/N**: 남은 연가가 보상 한도를 넘거나 어차피 소멸한다면 N으로 두세요. 그러면 포기하는 보상비를 0원으로 계산합니다.
- 비율(86%)과 분모(30)는 `산식 · 공휴일` 탭, 연가 1건의 사용일수(주연·야연·당연1 = 1일, 당연2 = 2일)는 `연가 차감일수` 탭에서 바꿀 수 있습니다.

예 (일반6 11호봉 3,580,000원, 시간외 13,692원): 보상비 1일 ≈ 102,627원. 연가 없이 초과 −10시간인 달에 야연(일반직 15시간)을 쓰면 지급 초과는 5시간(68,460원)만 늘어 약 −34,167원, 연가를 안 쓰는 편이 낫습니다.

`비움`은 근무교환 등으로 그 날 산입이 0인 경우입니다. 교환으로 다른 날 근무가 늘면 그 날짜도 따로 수정하세요. 이 비교는 금전 계산일 뿐 연가 승인, 보상 대상 여부, 보상 한도, 지급 기준일 현재 호봉, 원 미만 처리를 판정하지 않습니다.

## 표시 금액의 원리

기본값은 제공된 9월 수당 산출표의 산식을 재현합니다.

- 주간 9.5시간, 야간 15.5시간. 별도 휴게시간 차감 없음.
- 당번 24.5시간, 반일근무 등은 기존 표의 계수를 사용. 설정에서 변경 가능.
- 일반직 야간연가 15시간, 소방직 야간연가 8시간. 나머지 휴가코드는 제공된 엑셀 계수를 사용합니다. 야간 병가·공가 기본 15시간, 야간 특가 기본 8시간입니다. 기관 규정과 다르면 날짜별 직접 지정 또는 코드 설정을 확인하세요.
- 월 총 산입시간 = 근무시간 + 휴가 산입시간 + 교육·출장 + 추가 활동 − 제외시간 + 월 조정값.
- 기준일 = 해당 월의 월~금 중 Python 대한민국 공휴일 목록과 사용자 추가/제외 설정을 적용한 날짜 수.
- 초과 인정시간 = 총 산입시간 − 기준일 × 8 − 휴일수당 대상일 × 8 + 기본시간 가산.
- 시간외수당은 초과 인정시간이 음수이면 0원. 화면에서는 음수를 그대로 표시합니다.
- 야간수당과 휴일수당은 별도로 계산합니다. 시간외수당이 0이어도 남을 수 있습니다.
- 야간은 야/당/야비 코드당 기본 8시간. 휴일수당은 토·일/공휴일의 주/당 코드당 1일.
- 월말 야간도 **근무 시작일이 속한 달**에 8시간 전부 귀속합니다. 실제 기관 정산 기준이 다르면 월 조정값을 사용하세요.
- 기본 설정은 월 총 산입시간의 소수점을 버리고 각 수당의 10원 미만을 버립니다. 엑셀 비번활동 시간은 월 합계의 소수점을 먼저 버리는 기존 방식도 재현합니다. 따라서 30분 추가가 항상 곧바로 수당 증가로 이어지지는 않습니다.
- 설정에서 시간 절사를 끄면 분단위 시뮬레이션을 할 수 있습니다. 이 경우 기존 엑셀 결과와 달라질 수 있습니다.
- 본봉은 처음 시작할 때 사용자·호봉 창(또는 설정 → 사용자)에서 직급·호봉으로 넣습니다. 봉급표에 없으면 본봉을 직접 입력합니다. 본봉은 연가보상비 계산에만 쓰며 화면에 본봉+수당 합계는 표시하지 않습니다.
- 단가는 제공된 2026년 수당 산출표에서 가져왔습니다. 향후 연도 인상은 자동 반영하지 않습니다.
- 지급한도, 별도 정액분, 기관별 예외, 연가보상비 지급 여부·한도, 공제, 승인 요건은 자동 판단하지 않습니다.

달력 옆 `추가 교육/근무 가정`에 시간을 넣으면 그만큼 더했을 때의 수당 증감을 한 줄로 보여줍니다. 예: 초과 인정시간 −50시간인 달에 8시간만 추가하면 시간외수당 증가액은 0원입니다. `월별 교육·근무 실익` 탭에서 동일한 추가시간을 각 달에 적용한 증감을 비교하세요. 순수 추가시간 비교이며, 교육 때문에 기존 근무가 없어지는 경우는 달력에서 근무 대체로 비교해야 합니다.

## 이번 10월 편성표의 확인사항

- 직원 A 10월 1일, 직원 B 10월 2일, 직원 C 10월 9일은 동일 날짜에 주간·야간 이름이 모두 존재합니다. `복합`으로 주간 9.5 + 야간 15.5 = 25시간 합산하고 확인사항을 표시합니다. 실제 근무가 맞는지 확인하세요.
- 직원 B 10월 1일 연가, 직원 D 10월 9일 연가는 비고를 읽어 주연으로 반영합니다.
- 직원 E 10월 2일 교육은 시간이 적혀 있지 않아 **임시 8시간**으로 가져옵니다. 날짜 편집에서 실제 시간으로 바꾸세요.
- 비고의 자유로운 문장, 복잡한 교환·시간단위 휴가 등은 완전 자동 해석 대상이 아닙니다. 메뉴(☰) → `가져오기 확인사항`과 날짜 메모를 확인하세요.
- 같은 날의 복합 근무는 날짜 편집의 `당일 인정시간 직접 지정`으로 총산입/야간/휴일을 수정할 수 있습니다. 직접 지정을 켰을 때 세 칸은 모두 직접 지정값으로 적용됩니다.
- 원본 파일에 저장된 수식 결과를 읽습니다. 결과가 없는 파일은 Excel에서 재계산·저장 후 가져오세요. 엑셀 파일 자체는 수정하지 않습니다.
- 현재 지원하는 형식은 이번 근무편성표와 앞서 제공된 9월 수당 산출표입니다. 임의의 다른 열 배치까지 범용 자동 판독하지는 않습니다.

| 소방 (국가직) | [국가공무원 복무규정 제14조](https://www.law.go.kr/법령/국가공무원복무규정/제14조) · [현장 소방공무원 복무규칙 제30조](https://www.law.go.kr/행정규칙/현장소방공무원복무규칙/제30조) (소방청 훈령) | 휴가 종류 · 교대제 근무자 휴가 1일은 8시간 기준, 주간·야간근무 휴가는 1일 → 소방 야간연가 8시간 산정 |

**훈령 제5조 정리:** ①~③은 원칙(24시간, 4개조 2교대)이고 ④는 예외입니다. 상황실장은 1호 재난, 2호 명절·연말연시·연휴, 3호 휴가(연가·병가·공가·특별휴가) 또는 교육훈련, 4호 그 밖의 효율적 운영(실무상 자체 내부결재)을 사유로 근무인원·근무시간을 달리 조정할 수 있습니다. 연가는 3호 "휴가"의 한 종류일 뿐이라, 근무에서 빠질 때 반드시 연가를 올려야 하는 것은 아닙니다. 실무상 실질적인 문제는 **연가를 쓰지 않고 남겨 연가보상비로 받는 것**이고, 이 프로그램은 그 금액 차이를 보여 줍니다. 제6조②(업무개시 30분 전 출근해 합동근무)는 주간 9.5시간·야간 15.5시간 산정과 맞습니다.

시작 안내·도움말의 제5조 표에서 2호 옆 **여름휴가 ▸**를 누르면 "여름 휴가철 근무체계 일시 조정 검토" 보고서가 열립니다. 검토 요지, 근거 규정, 2·3·4호 적용 검토, 제2호 해석상 유의점, 연가 처리 구분(사전 승인한 변경 근무표의 비번일은 원칙적으로 연가 불필요 등), 결론, 공문(내부결재) 작성 예시(관련: 지방공무원 복무규정 제5조, 상황실 운영 규정 제5조제4항)가 담겨 있습니다. 조문 해석이며 유권해석은 아닙니다.

근무시간·근무일은 기관(자치단체장)이 정하도록 위임되어 있지만, 연가 일수와 연가보상비 자체는 대통령령·조례가 정합니다. 근무조정 승인과 수당 지급은 기관 판단이며 이 프로그램은 금액만 비교합니다. 소방 야간연가 8시간은 현장 소방공무원 복무규칙 제30조②(휴가 1일 = 8시간 기준)와 맞습니다. 다만 이 조문은 연가 차감 기준이고, 상황실 소방직에 적용되는지는 확인이 필요합니다. 일반직 야간연가 15시간의 직접 근거는 아직 확인하지 못했습니다.
